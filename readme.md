## API Testing

## Overview

This is a test of different APIs, showcasing how to interact with various services to retrieve data. The main focus is on three different APIs: the Random User Generator API, the OpenWeatherMap API, and the NASA Earth Imagery API. Each API serves a unique purpose and demonstrates different methods of making requests and handling responses.

## APIs Included

### 1. Random User Generator API

- **Description**: This API generates random user data for application testing.

### 2. OpenWeatherMap API

- **Description**: This API provides weather data for a specified city.

### 3. NASA Earth Imagery API

- **Description**: This API retrieves satellite imagery for specified geographic coordinates and dates.

## Methods Used

- Used `fetch` for making requests in a modern and promise-based way.
- Used `require` for importing necessary modules.
- Used `axios` for handling HTTP requests efficiently with additional features like automatic JSON parsing and request cancellation.

## Conclusion

This serves as a practical demonstration of how to interact with different APIs using JavaScript.
